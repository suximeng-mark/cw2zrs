# 值日生插件
Class Widgets 2 插件：显示今日值日生，支持自定义分组、多种轮换方式、考勤统计、明日预告与定时提醒。

# 功能
- 卡片式显示今日值日生（姓名 + 任务），支持紧凑模式与深浅色主题
- 自定义任意数量的小组及成员，支持批量导入
- 按周 / 每天 / 工作日自动轮换，可设置起始日期
- 假期安排：假期内不轮换，结束后自动衔接下一组
- 「上一组 / 下一组 / 重置」手动切换值日组
- 今日考勤：成员请假标记，自动统计每人值日次数与请假次数
- 显示设置：四个区域字号、成员排列方式、姓名与任务配对样式
- 明日预告：部件中显示明日（含周末 / 假期标记）的值日组与成员
- 值日提醒：每天指定时间弹出系统通知，可设置假期不提醒
- 配置导入 / 导出，值日表导出 CSV（Excel 可编辑）与 HTML（可打印 / 存 PDF）

# 使用
1. 在 Class Widgets 2 的「设置 → 插件」中导入打包好的插件
2. 在「自定义」中添加「今日值日生」小组件
3. 在插件设置页配置值日小组、成员和起始日期
4. 重启 Class Widgets 2 使配置生效
5. 查看今日值日生小组件显示是否正确
6. 大功告成!
