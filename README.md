# 值日生插件
Class Widgets 2 插件：显示今日值日生，支持自定义分组并按周/日轮换。
# 功能
- 卡片式显示今日值日生（姓名 + 任务）
- 支持自定义任意数量的小组及成员
- 按周自动轮换值日小组（可设置起始日期）
- 提供「上一组 / 下一组 / 重置」手动切换按钮
- 跟随 Class Widgets 深浅色主题
# 使用
1. 在 Class Widgets 2 的「设置 → 插件」中导入打包好的插件
2. 在「自定义」中添加「今日值日生」小组件
3. 在插件设置页配置值日小组、成员和起始日期
4. 重启 Class Widgets 2 使配置生效
5. 查看今日值日生小组件显示是否正确
6. 大功告成!
