# 值日生插件

Class Widgets 2 插件：在桌面显示今日值日生，支持自定义分组、多种轮换模式、考勤统计、明日预告与每日定时提醒。

**2.0.0 起支持多套值日方案**：例如「单周轮到一组」和「双周轮到一组」可以各自独立保存，一键切换，互不干扰；每套方案的历史考勤与统计也各自隔离，旧版配置会自动迁移成一个默认方案。

## 功能

- 卡片式显示今日值日生（姓名 + 任务），普通 / 紧凑两种形态自适应
- **多套值日方案**：可建立多套「组员 + 轮换方式 + 假期」的方案并一键切换，每套的考勤历史与统计独立统计；最后一个方案不可删除
- 自定义任意数量的小组及成员（姓名与职责一一对应）
- 三种轮换模式：按周轮换 / 每天轮换 / 工作日轮换（可设置起始日期，假期自动跳过）
- **值日步长**：可设为「每 2 天（周）算一次值日」，同一组连续值日满 N 个轮换单位后再换下一组，假期不占用步长
- **临时合并**：月历点选某天，填入任意另一天（不限于相邻），这两天合计算一次值日（临时调整，取消即恢复，与常驻步长互不干扰）
- **临时调整成员任务**（当轮有效）：在「临时调整」页可让本轮值日的两名成员**互换任务**，或单独把某人任务临时改成别的；只在当前这一轮生效，轮换到下一组 / 下一轮自动恢复，也可手动「全部恢复」
- 「上一组 / 下一组 / 重置」手动切换
- 成员考勤（请假标记）与按人统计、最近记录查看
- **多套值日方案**：可保存多套分组/轮换/假期配置（如单双周、不同班级），在「轮换管理」页一键切换，每套方案独立记录考勤历史；界面显示与提醒设置为全局共用
- **历史记录浏览**：设置页新增「历史记录」页，按月翻查过往值日与请假明细，支持按成员筛选
- **统计图表**：最近 12 周值日天数柱状图（下方橙色数字为该周请假人次）、各组值日天数对比条，纯 QML 绘制、不引第三方图表库
- 自定义假期时间段
- 显示设置：组名 / 徽标 / 姓名 / 任务 四个独立字号与**独立显隐开关**、三种成员排列方式、四种姓名-职责配对样式，设置页带实时预览
- 工作日轮换的周末处理方式：合并计一天 / 周末不轮换 / 周末逐日计档
- 月历视图：点选日期即可标记放假、临时调班，或与任意另一天合并计 1 档，直接看到当日值日组
- 分节备份与迁移：界面设置 / 人员设置 / 轮换配置及方式 / 请假记录 可按需勾选导出导入，兼容旧版平铺格式
- 导入导出通过**系统文件对话框**选择路径，无需手动输入（配置/备份选文件，值日表选目录）
- 明日值日预告（部件内显示次日值日组，假期带徽标）
- 每日定时提醒：自定义时间（HH:MM），Windows 系统通知，可设置假期不提醒，支持立即测试
- 配置导入 / 导出（JSON）
- **备用更新服务**：官方插件广场不可用时的备用通道。可填**多个更新地址**（每行一个），插件会按顺序自动依次尝试，前一个不通就用下一个；全部不通时会列出每个地址失败的原因。内置源为本插件的 GitHub Release，留空即只查内置源。自定义源返回 JSON 含 `version` / `download`，或直接兼容 GitHub Release API 格式
- 一键导出未来 1~26 周值日表（**Excel + CSV + HTML**，UTF-8-SIG，Excel/WPS 直接打开不乱码；带「轮次」列，步长 > 1 时标注第几次的第几天。xlsx 带加粗表头、冻结首行、自动筛选、列宽与假期/周末底色，且不依赖任何第三方库）
- 跟随 Class Widgets 深浅色主题

## 使用

1. 在 Class Widgets 2 的「设置 → 插件」中导入打包好的 `.cwplugin`
2. 在「自定义」中添加「今日值日生」小组件
3. 打开插件设置页，配置值日小组、成员、起始日期与轮换模式；在「轮换管理」中可设置值日步长（如两天算一次值日），也可在月历上把任意两天临时合并计 1 档；本轮需要调换活儿时去「临时调整」页；需要单双周等多套安排时，在「轮换管理」页顶部的「值日方案」中新建并切换
4. 按需调整显示样式、明日预告与值日提醒
5. 重启 Class Widgets 2 后查看小组件显示是否正确

## 数据存储

插件数据**全部存放在插件自己的文件夹**内，不写入核心 `configs.json`（该文件中本插件的配置段为空 `{}`），备份、迁移或替换测试数据只需复制下面两个文件：

```
plugins/com.studentondutyshow.com/data/
├── config.json    # 值日方案（active + profiles，方案内含分组/轮换/假期）、显示设置、提醒设置
└── history.json   # 每日考勤快照与统计记录（按方案隔离，每条含 profile 字段，最多保留 400 天）
```

升级到 1.6.0 首次启动时，旧版存放在核心配置中的数据会自动一次性迁移到上述文件，并清空核心配置中的残留字段；升级到 1.13.0 时，旧版平铺配置会自动包装成单个「默认方案」、历史记录自动打上方案标签，无需手动处理。
