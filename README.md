# 值日生插件

Class Widgets 2 插件：在桌面显示今日值日生，支持自定义分组、多种轮换模式、考勤统计、明日预告与每日定时提醒。

## 功能

- 卡片式显示今日值日生（姓名 + 任务），普通 / 紧凑两种形态自适应
- 自定义任意数量的小组及成员（姓名与职责一一对应）
- 三种轮换模式：按周轮换 / 每天轮换 / 工作日轮换（可设置起始日期，假期自动跳过）
- **值日步长**：可设为「每 2 天（周）算一次值日」，同一组连续值日满 N 个轮换单位后再换下一组，假期不占用步长
- 「上一组 / 下一组 / 重置」手动切换
- 成员考勤（请假标记）与按人统计、最近记录查看
- 自定义假期时间段
- 显示设置：组名 / 徽标 / 姓名 / 任务 四个独立字号与**独立显隐开关**、三种成员排列方式、四种姓名-职责配对样式，设置页带实时预览
- 工作日轮换的周末处理方式：合并计一天 / 周末不轮换 / 周末逐日计档
- 月历视图：点选日期即可标记放假或临时调班，直接看到当日值日组
- 分节备份与迁移：界面设置 / 人员设置 / 轮换配置及方式 / 请假记录 可按需勾选导出导入，兼容旧版平铺格式
- 导入导出通过**系统文件对话框**选择路径，无需手动输入（配置/备份选文件，值日表选目录）
- 明日值日预告（部件内显示次日值日组，假期带徽标）
- 每日定时提醒：自定义时间（HH:MM），Windows 系统通知，可设置假期不提醒，支持立即测试
- 配置导入 / 导出（JSON）
- 一键导出未来 1~26 周值日表（CSV + HTML，UTF-8-SIG，Excel 直接打开不乱码；带「轮次」列，步长 > 1 时标注第几次的第几天）
- 跟随 Class Widgets 深浅色主题

## 使用

1. 在 Class Widgets 2 的「设置 → 插件」中导入打包好的 `.cwplugin`
2. 在「自定义」中添加「今日值日生」小组件
3. 打开插件设置页，配置值日小组、成员、起始日期与轮换模式；在「轮换管理」中可设置值日步长（如两天算一次值日）
4. 按需调整显示样式、明日预告与值日提醒
5. 重启 Class Widgets 2 后查看小组件显示是否正确

## 数据存储

插件数据**全部存放在插件自己的文件夹**内，不写入核心 `configs.json`（该文件中本插件的配置段为空 `{}`），备份、迁移或替换测试数据只需复制下面两个文件：

```
plugins/com.studentondutyshow.com/data/
├── config.json    # 分组、成员、假期、轮换设置、显示设置、提醒设置
└── history.json   # 每日考勤快照与统计记录（最多保留 400 天）
```

升级到 1.6.0 首次启动时，旧版存放在核心配置中的数据会自动一次性迁移到上述文件，并清空核心配置中的残留字段，无需手动处理。
